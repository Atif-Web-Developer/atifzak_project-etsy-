Ek dafa ye steps karein. Phir har hunt website ke saath Google Sheet ke Product selection aur Competitors selection tabs mein bhi save hoga.

  1. Apni Google Sheet kholein (ma'am wali “stock sheet” View only hai – us ki copy banayein: File → Make a copy, ya nayi sheet) → Extensions → Apps Script.
  2. Code.gs: editor mein sab kuch mita kar ye code paste karein: Download
    Sync key is file mein pehle se hai. Ye eBay Dropshipping wale Code.gs se alag hai – alag sheet mein lagayein.
  3. Save (Ctrl+S).
  4. Deploy → New deployment → ⚙ → Web app. Execute as: Me, Who has access: Anyone → Deploy → permission allow karein.
  5. Web app URL (aakhir mein /exec) copy kar ke neeche paste karein.
